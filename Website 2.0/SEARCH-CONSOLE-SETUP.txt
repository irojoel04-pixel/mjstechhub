MJSTECHHUB.COM — GOOGLE SEARCH CONSOLE

1. Open Google Search Console:
   https://search.google.com/search-console

2. Add a Domain property:
   mjstechhub.com

3. Verify ownership through DNS using the TXT record Google provides.

4. After verification, open:
   Indexing -> Sitemaps

5. Submit:
   https://mjstechhub.com/sitemap.xml

6. Use URL Inspection on:
   https://mjstechhub.com/
   https://mjstechhub.com/about.html
   https://mjstechhub.com/work.html
   https://mjstechhub.com/projects.html
   https://mjstechhub.com/writing.html
   https://mjstechhub.com/contact.html

7. Once each important URL is publicly reachable, request indexing where appropriate.

Before submission, confirm:
- HTTPS works.
- https://mjstechhub.com/robots.txt loads.
- https://mjstechhub.com/sitemap.xml loads.
- CSS, JS and images load normally.
